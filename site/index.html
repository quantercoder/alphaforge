    Live prices

    Streams real-time stock trades from Alpaca's free IEX feed for up to 30 tickers, during market hours (9:30 to 16:00 New York). Every ticker you open is live tracked; past 30, the one you opened longest ago drops off. Use the API key from an Alpaca paper account: it can read market data and can't touch real money.

    Keys go only to stream.data.alpaca.markets. They're saved in this browser only if you tick the box.

    Commands

    Type in the command line: suggestions appear as you type, matching tickers, company names and functions. Use the arrow keys and Enter, or Tab to complete. Any letter you press outside a field jumps to it.
