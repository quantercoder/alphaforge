Live prices

Streams real-time trades from Alpaca's free IEX feed into this page. Use the API key from an Alpaca paper account: it can read market data and can't touch real money.

Keys go only to stream.data.alpaca.markets. They're saved in this browser only if you tick the box.

Commands

Type in the command line and press Enter (GO). Any key you press outside a field jumps to it.
